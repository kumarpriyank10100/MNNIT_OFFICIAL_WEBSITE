# 🌐 NIT Allahabad Website Frontend Replica 🏫

A fully responsive frontend replica of the official **NIT Allahabad (MNNIT)** website, designed to mirror its original layout, navigation structure, and user experience.

---

## ✨ Overview

This project rebuilds the MNNIT website UI using modern web technologies to ensure a smooth, responsive, and accessible experience across all devices. It retains the institutional design language while modernizing the frontend for clarity, consistency, and speed.

---

## 🔹 Features

✔️ **Responsive Layout** – Optimized for desktops, tablets, and mobile devices  
✔️ **Structured Navigation Bar** – Multi-level menus for fast, intuitive access  
✔️ **Smooth Scrolling & Transitions** – Enhances user interaction and readability  
✔️ **Modern UI Components** – Buttons, cards, grids styled with accessibility and usability in mind  
✔️ **Semantic HTML & SEO-ready Markup** – Ensures structural clarity and search engine friendliness

---

## 🛠️ Tech Stack

- **HTML5** – For semantic, accessible structure  
- **CSS3** – Custom styles for layout, spacing, responsiveness, and animation  
- **JavaScript (Vanilla)** – For basic interactivity (dropdowns, mobile nav toggles)
